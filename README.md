# Smile Storm
🎉 在线体验地址
https://chuccooo.github.io/smilesmile/

手机、平板、电脑浏览器直接打开即可（HTTPS 环境，摄像头权限正常）。右侧预览面板也已打开——预览环境无摄像头权限，实测请用手机或浏览器新标签页打开上面的链接。
一个可在手机和电脑浏览器运行的 AR 表情互动原型：微笑持续下起细小冷色光雨，雨滴触碰头部会溅出水花和涟漪；大笑触发蓝紫色球形烟花，持续大笑 5 秒会播放 2 秒全屏垂柳烟花瀑布，烟花粒子会与用户头部产生物理碰撞。

## 体验方式

1. 用 HTTPS 在线地址或 `localhost` 打开页面。
2. 点击“开启摄像头”，允许摄像头权限。
3. 面对镜头微笑，观察雨滴；张嘴大笑，观察首轮烟花。
4. 保持大笑 5 秒，观察横跨全屏、2 秒内结束的蓝色垂柳烟花瀑布。
5. 烟花出现后左右移动头部，粒子会被头部轮廓弹开。
6. 右上角打开“灵敏度 · 性能”，可调节 30%—95% 表情灵敏度和 40%—100% 烟花数量，并观察实时分数、阈值与粒子预算。
7. 没有摄像头时可点击“不使用摄像头，先看演示”；自动流程也包含 5 秒持续大笑触发。

## 技术方案

- MediaPipe Face Landmarker：在浏览器本地输出 478 个脸部关键点及表情 Blendshape 分数。
- Canvas 2D：六档冷暖微光、三款星芒纹理与全屏光幕在启动时预烘焙为小型 Canvas 素材，运行时复用 `drawImage`；雨丝、水花、涟漪和三类垂柳烟花按景深与色调批量绘制，避免大量 DOM、渐变和阴影计算。
- 椭圆碰撞体：根据脸部关键点包围盒实时拟合头部，粒子做穿透修正、法线反射和阻尼。
- 表情状态机：微笑和大笑分别使用不同的进入/退出阈值（迟滞），避免阈值附近抖动；UI 灵敏度会连续映射阈值，无需刷新即可校准。
- 自适应性能：低性能设备减少推理频率和粒子预算；连续低帧率时自动降载、稳定后渐进恢复；设备像素比最大取 2；页面在后台时暂停计算。

```text
摄像头帧
  └─ MediaPipe（端侧）
      ├─ Blendshapes → 迟滞状态机 → 雨 / 烟花触发
      └─ Face landmarks → 头部椭圆碰撞体
                              └─ Canvas 粒子物理与绘制
```

## 本地运行

要求 Node.js 22+ 和 pnpm。

```bash
pnpm install
pnpm dev
```

打开终端显示的 `http://localhost:3000`。摄像头只能在 HTTPS 或 localhost 环境调用。

生产构建：

```bash
pnpm build
```

## 关键边缘情况

| 场景 | 处理 |
|---|---|
| 用户拒绝摄像头 | 显示可操作提示，并保留演示模式 |
| 没有摄像头或被占用 | 区分错误原因，不让页面白屏 |
| 未检测到脸 | 表情分数回落到中性，隐藏碰撞体 |
| 分数在阈值附近波动 | 进入/退出使用不同阈值，并做指数平滑 |
| 用户表情幅度较小 | 默认灵敏度 72%；可根据实时分数上调，阈值同步降低 |
| 灵敏度过高 | 面板提示误触风险；大笑仍要求笑容与张嘴同时成立，并保留冷却 |
| 持续大笑 | 上升沿先触发普通烟花；连续满足 5 秒后仅触发一次烟花瀑布，全部粒子最长 1.93 秒、光幕 1.98 秒 |
| 烟花瀑布性能 | 不提高硬预算；触发时回收旧粒子，低端机最多约 138 个、标准设备最多约 244 个动态锚点；数量滑块只在预算内缩放 |
| 低帧率发生在特效中 | 降低质量档位后立即回收远景星点、雨滴和余烬，必要时继续回收尾部粒子，保证总数回到新预算内 |
| 低端手机 | 推理约 12 Hz、基础粒子预算 170；标准设备约 20 Hz、预算 300；连续低帧率时最低降至 62% |
| 标签页进入后台 | 暂停推理和绘制；恢复时限制最大时间步，避免粒子穿透 |
| 画面 `cover` 裁切及镜像 | 关键点使用同样的缩放、裁切和镜像映射 |
| 单帧推理异常 | 忽略该帧，动画循环继续 |
| 用户偏好减少动画 | 尊重 `prefers-reduced-motion`，压缩界面过渡 |

## 成本与隐私

- 推理、物理、渲染全部在用户设备完成，不需要业务后端或 GPU 服务。
- 视频不上传、不保存；服务器只托管静态资源和轻量页面代码。
- 主要变量成本是 CDN 流量。MediaPipe 模型约 3.6 MB，浏览器可缓存；后续可把模型与 WASM 自托管并设置长缓存。
- 单人脸已经满足直播前置摄像头场景，`numFaces: 1` 可减少无收益计算。

## 已知限制与下一步

- 不同人种、光照、遮挡和摄像头角度会改变表情分数，正式上线前应收集匿名分数分布并校准阈值。
- 当前碰撞体是稳定且便宜的椭圆近似，不是逐三角形脸部网格；这是原型阶段的 ROI 取舍。
- 生产版建议把同步推理迁移到 Web Worker/OffscreenCanvas（浏览器支持时），并用真实设备建立性能基线。
